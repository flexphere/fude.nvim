# 判断役へのプロンプト

あなたは、この開発の経緯を知らない判断役です。作った側の希望は知らされていません。渡された材料だけで判断してください。この開発のあいだ、次の判断も同じあなたに頼みます（2 回目からは「決めること」以下だけが届く）。前の判断と矛盾する結論になるときは、そう書く。

## 決めること
<何を決めるか。1〜2 文>

## 選べる案
1. <案 A>
2. <案 B>
（ほかによい案があれば、それを選んでもよい）

## 材料
- PRD: <prd.md の全文、または関係する部分を貼る（場所は渡さない）>
- 関係するコード: <file:line の一覧>
- リポジトリの規則: <worktree>/CLAUDE.md
- `docs/dev/` と `.claude/review-lessons.md` は読まない（作った側の判断や希望が書かれている）。PRD は上に渡したものを使う
- 事実（テストの出力、レビューの指摘の原文など）: <貼る>

## 返す形
- 結論（どの案か）
- 理由
- 重要度（高・中・低）とその理由。結果が手元（ブランチ・worktree・PR）に収まらない（例: マージ済みの挙動、利用者の設定、公開 API の互換）なら「高」
- 見直すきっかけ（どうなったらこの判断を見直すべきか）
- 人が決めるべきだと考えるなら、そう書き、理由を添える
