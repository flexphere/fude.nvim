# lua/fude/chat/data.lua

Pure helpers for the chat (covered by `make check-purity`). Command line: `is_uuid(s)` (lowercase hyphenated — the only form claude accepts, and a stored id is passed to a command line), `build_tool_names(allowed_tools)` (`Bash(git diff:*)` → `Bash`, each once, `mcp__*` left out), `has_setting_sources(extra_args)` (`--setting-sources` or `--setting-sources=…` among the extra arguments), `find_chat_root(review_mode, repo_root, local_session)` (claude's working directory: the GitHub review's start root or the local session's worktree root), `build_claude_args({ cmd, session_id, resume, allowed_tools, system_prompt, extra_args, user_settings_only })` (`cmd -p --output-format stream-json --verbose --include-partial-messages (--session-id|--resume) <id> --permission-mode dontAsk [--setting-sources user] --tools <names> [--allowedTools <spec>...] [--append-system-prompt <text>] <extra_args...>`: `--tools` makes only the named built-in tools exist — no Edit/Write with the default list, which is still not strictly read-only: the allowed `git diff`/`log`/`show`/`blame` write a file with `--output=<path>`; the documented ways to close that are `chat.args = { "--disallowedTools", "Bash(git *--output*)" }` (an option, so it also ends the variadic `--allowedTools` list) or an `allowed_tools` without git —, `--allowedTools` restricts their form, and `PERMISSION_MODE` `dontAsk` denies the rest instead of prompting whatever the user's default mode is; `user_settings_only` — passed by `chat.lua` for every review that is not local — adds `--setting-sources user` (`USER_SETTING_SOURCES`) so the project's and local settings files of a pull request's checkout, with their hooks and allow rules, are not read (`claude -p` skips the workspace trust dialog), unless `extra_args` set the option themselves, in which case only the user's is passed; a local review reads the project's settings; the user's own allow rules and MCP permissions still apply by design, and `extra_args` come last, which overrides a single-value option but may only add to a collecting one such as `--allowedTools`. Checked with claude 2.1.332: with `--setting-sources user` an MCP server of the checkout's `.mcp.json` is not started, without it it is; the project's `CLAUDE.md` was not checked). Prompt: `build_system_prompt(state)` (only what cannot change during a conversation — GitHub: PR number, URL, base/head; local: the branch — because claude records the system prompt on a conversation's first request and reuses that record on every `--resume`, ignoring text passed later), `build_prompt_context(state)` (the lines put in front of every question instead: in local review one `[Review context — base branch: …; scope: …]` line, the commit SHA in the commit scope; in a GitHub review `[Review context — scope: commit <sha> …]` — the same wording, from the module-local `commit_scope_text` — while `state.scope == "commit"`, none in the full PR scope; the GitHub system prompt says that a question may start with that commit) and `build_prompt_input(context, prompt)`. Stream: `split_stream_chunk(pending, chunk)` → `lines, rest`, `parse_stream_line(line)` → events (`init`, `message_start`, `text` from `text_delta` only since the complete assistant message repeats it, `tool` from the complete assistant message where name and input are whole, `result` with `ok`/`text`/`error` — `errors` list, else `result`, else subtype; unknown types, malformed lines and lines with a string `parent_tool_use_id`, i.e. sub-agent output, yield nothing; nested fields are type-checked against JSON null), `is_session_not_found(err)` / `is_session_in_use(err)` / `find_session_retry(resumed, err)`, `format_tool_use(name, input, root)` (`Read lua/fude/foo.lua`, root-relative path, first line of a Bash command, cut at `TOOL_DETAIL_WIDTH` without splitting a multi-byte character). Store: `build_empty_chat()`, `build_message(role, text, status, at, err)` (assistant `status`: `done`/`cancelled`/`error`, the last with its message in `error`), `serialize_chat(chat, key)` / `deserialize_chat(text)` (`{ version, key, session_id, started, messages }`; every field validated on load, a non-UUID session id dropped with its `started`; no directory is stored). Panel text: `format_question_lines(prompt)` (`## You`, the question, `## Claude`, ending on the empty line the answer is written onto), `format_answer_end_lines(status, err, has_text)` (`*(interrupted)*` / `**Error:** …`), `format_chat_lines(messages)` (the stored conversation, line for line what the live rendering produces, a stored failure's `**Error:**` line included), `build_selection_text(path, start_line, end_line, lines, filetype)` (`<path>:L<start>-L<end>` or `:L<line>`, `[No Name]` without a path, a fence longer than any backtick run in the selection), `format_base_path(path)` (`<path> (base version)`), `calculate_panel_width(width, columns)` (at least `MIN_PANEL_WIDTH`, at most half the columns — that bound wins), `find_panel_split(position)`.
