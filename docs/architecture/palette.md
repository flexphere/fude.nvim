# lua/fude/palette.lua

`:FudeCommandPalette` command palette. Pure helpers: `rhs_invokes_command(rhs, name)` (does a mapping rhs run the command as its *first* Ex command — the rhs must start with an optional `<Esc>`, then `<Cmd>` or `:`, optional `<C-u>` / `'<,'>`, then the name followed by a non-identifier character; the wrapper is matched case-insensitively but the name exactly, since user commands are case-sensitive. Anchoring at the start, rather than scanning the rhs, is what rules out names inside string literals or after a `|` separator without an Ex parser; a mapping that runs the command only after `|` is deliberately not reported), `find_keymap_for_command(keymaps, name)` (first matching lhs; Lua-callback mappings have no rhs and are skipped), `build_palette_entries(cmds, state, keymaps, category_order?)` (filters by `available(state)` and `palette ~= false`, attaches the key, orders by category then registry order), `calculate_palette_widths(entries)` / `format_palette_entry(entry, widths)` (aligned `[Category]  desc  :Name  key` line for `vim.ui.select`; in Telescope/snacks the category is `Title`, the description normal, the name `Comment`, the key `Special`), `calculate_palette_layout(widths, count, columns, lines)` (absolute window size: widest row + padding, `count + 5` rows, clamped to the editor — Telescope uses it through `themes.get_dropdown`, snacks through the `select` preset, both without a preview pane so the palette stays a compact centered menu regardless of the user's picker defaults), `format_key_lhs(lhs, mapleader)` (restores the `<leader>` token that `nvim_get_keymap` expands). Side effects: `collect_keymaps(modes, buf)` (buffer-local then global mappings with lhs passed through `format_key_lhs`, skipping a global mapping whose lhs is shadowed by a buffer-local one; `x` mode is included when the palette was opened with a range), `execute(entry, ctx)` (runs the command via `vim.cmd({ cmd = name, range = ... })` from the window the palette was opened in, forwarding `ctx.range` only to `range = true` commands), `resolve_visual_range()` (when visual mode is still active — a `<Cmd>FudeCommandPalette<CR>` mapping passes no range — leaves visual mode and returns the `'<`/`'>` line range), `open(opts)` (`opts.range = { line1, line2 }` from `:'<,'>FudeCommandPalette`, else derived via `resolve_visual_range`; routes to `show_telescope` / `show_snacks` / `show_vim_select` by `file_list_mode`, with the same missing-plugin fallbacks as `scope.lua`).
