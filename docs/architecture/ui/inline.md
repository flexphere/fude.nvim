# lua/fude/ui/inline.lua

Inline (virt_lines) comment box rendering. `format_comments_for_inline(comments, format_date_fn, opts)` builds bordered comment boxes for use as `nvim_buf_set_extmark` `virt_lines`. The box border label shows `[pending]` for pending comments, else `[resolved thread]` for a resolved thread's head comment only (the oldest one, with no `in_reply_to_id`) — since resolved state is thread-level and propagated to every comment, the label is not repeated on replies. A multi-line thread head is titled with its range (`Comment L20-L29 [pending]`, via `data.get_comment_line_range` + `format.format_line_range`) under the same head-only rule. Reads the current window's text width via `vim.api`/`vim.fn` to size boxes, which is why it lives outside the pure `ui/format.lua`.
