# lua/fude/ui/extmarks.lua

Extmark management: `flash_line`, `highlight_comment_lines`, `clear_comment_line_highlight`, `refresh_extmarks`, `refresh_visible_extmarks` (re-renders every window showing a normal buffer, used after a local scope switch), `clear_extmarks`, `clear_all_extmarks`. `refresh_extmarks` also colors the line numbers of every multi-line comment range (`number_hl_group` from `comment_range.number_hl`, both styles, clamped to the buffer by the module-local `highlight_range_numbers`), and `update_inline_hint` marks the ranges of the comments on the cursor line through the module-local `mark_cursor_ranges` (line numbers switched to `comment_range.cursor_number_hl` at a higher priority, plus a `build_range_start_marker` EOL text on each range's first line in `start_marker_hl`; both in the hint namespace, removed by `clear_inline_hint`) — a multi-line comment is drawn on its last line, so these show where it starts. No background (`line_hl_group`) or sign is used, so diff colors and gitsigns stay visible. Uses lazy `require("fude.comments")` to avoid circular dependencies. `refresh_extmarks` also renders the `draft` indicator from `drafts.file_markers(rel_path)` (EOL virt_text, both virtualText and inline modes), and clears the buffer instead of rendering while `local/session.in_commit_scope()` (the buffer is a checked-out past commit, so working-tree positions would land on unrelated lines); it maps the buffer with `local/session.relative_path`, which is relative to the local session's worktree root (falling back to `diff.to_repo_relative` outside local mode) so a `:cd` out of the worktree does not blank every reviewed buffer. A module-local `render_virt_text_indicators(buf, line, comments)` builds the EOL indicators (comment count, pending, resolved `resolved.label` at priority 43 when `util.all_comments_resolved`); it is used both for the virtualText style and, in the inline style, as the fallback for resolved comments whose box is hidden by `:FudeReviewToggleResolved` (so both paths show an identical indicator).
