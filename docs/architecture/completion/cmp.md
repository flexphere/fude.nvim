# lua/fude/completion/cmp.lua

nvim-cmp source adapter for `completion/init.lua`. `source.new()` builds the source; `is_available()` delegates to `require("fude.completion").is_enabled()`, the trigger characters are `@`, `#` and `_`, and `get_keyword_pattern()` matches `@\w*`, `#\d*` and `_` followed by letters, digits, spaces, `[]`, `/` and `()`, so the typed token is matched against the candidates. `complete(params, callback)` passes `params.context.cursor_before_line` to `get_context` and, for `mention` / `issue` / `commit`, calls `fetch_mentions` / `fetch_issues` / `fetch_commits` with `params.context.bufnr` as the request buffer, answering the item list (empty for any other context). nvim-cmp sorts candidates itself, so `_commit` candidates may not stay in the order `fetch_commits` returned. Registered by the user with `require("cmp").register_source("fude", require("fude.completion.cmp").new())` (see README).
