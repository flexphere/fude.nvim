# lua/fude/util.lua

Shared utility functions. `is_null(v)` checks for both `nil` and `vim.NIL` (JSON null compatibility across Neovim 0.11/0.12). `null_to(v, default)` replaces a JSON null with `default` (use it instead of the `and-or` idiom, which cannot map null to nil). `path_less(a, b)` compares paths byte by byte, the order git and the GitHub PR file list use (explicit loop, since PUC Lua's `<` uses locale-dependent `strcoll`); used by `local/session.build_changed_files`. `all_comments_resolved(comments)` checks whether every comment in a list is resolved (false for empty lists); shared by `comments/data.lua`, `ui/format.lua`, and `ui/extmarks.lua` so the "all resolved" rule stays consistent. `copy_to_clipboard(text)` sets `"` and, with a clipboard provider, `+` (never reading `+` back, which may block under OSC 52); returns whether `+` was set. Used by the side panel's `copy_path` and `pr.lua`'s error float `c`. `reset_selection_on_prompt_change(picker)` wraps a Telescope picker's `_do_selection` so that a refresh whose prompt differs from the previous one (`should_reset_selection(prompt, last_prompt)`, pure) selects the first row (`get_reset_row`) whatever `selection_strategy` is in effect, while a refresh with the same prompt keeps the picker's own strategy (the toggle picker's `follow`); every fude Telescope picker (files, scope, palette, stack, the `pr.lua` pickers, the toggle picker) goes through it before `:find()` — snacks.picker already starts again from the top on a new pattern (its matcher clears the list). `open_url(url, reason)` opens a URL with `vim.ui.open` (ERROR on failure) or, when `url` is nil, shows `reason` as an INFO, so a `url, reason` pair from `data.find_comment_url` / `sidepanel.build_scope_url` passes straight through; every `o` (open on GitHub) key uses it.
